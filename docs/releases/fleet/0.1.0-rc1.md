# Mercury Fleet 0.1.0-rc1

**Release candidate.** First RC for the 0.1.0 Fleet release, published to the npm dist-tag **`rc`**
rather than `latest`, so a plain `npm install @aywengo/mercury-fleet` will not pick it up:

```bash
npm install -g @aywengo/mercury-fleet@rc
```

Fleet is a separate package with its own version, so its RC is tagged independently of the host
(`fleet-v0.1.0-rc1` vs `host-v0.1.0-rc1`) and the two need not move together.

First public release of Fleet. Phase 0: host registry and probe. No dispatch.

## Install

From the same checkout as the host:

```bash
npm run fleet -- hosts list
```

Or:

```bash
npm install -g @aywengo/mercury-fleet
```

Requires Node.js ≥ 22.18. Operator guide: [`fleet/README.md`](../../../fleet/README.md).

`fleet --version` prints `mercury-fleet 0.1.0-rc1`.
`GET /healthz` includes `"product": "fleet"` and `"version": "0.1.0-rc1"`.

## What this is

Register independent Mercury hosts, probe them, and run `fleet serve`. Fleet
speaks HTTP only and does not import host code or share a database.

## Not in this release

Starting Runs, routing, or moving Runs between hosts.

Full notes: [`fleet/CHANGELOG.md`](../../../fleet/CHANGELOG.md).
