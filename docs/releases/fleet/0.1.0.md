# Mercury Fleet 0.1.0

First public release of Fleet. Phase 0: host registry and probe. No dispatch.

## Install

From the same checkout as the host:

```bash
npm run fleet -- hosts list
```

Or:

```bash
npm install -g @aywengo/mercury-fleet
```

Requires Node.js ≥ 22.18. Operator guide: [`fleet/README.md`](../../../fleet/README.md).

`fleet --version` prints `mercury-fleet 0.1.0`.
`GET /healthz` includes `"product": "fleet"` and `"version": "0.1.0"`.

## What this is

Register independent Mercury hosts, probe them, and run `fleet serve`. Fleet
speaks HTTP only and does not import host code or share a database.

## Not in this release

Starting Runs, routing, or moving Runs between hosts.

Full notes: [`fleet/CHANGELOG.md`](../../../fleet/CHANGELOG.md).
