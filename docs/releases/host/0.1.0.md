# Mercury host 0.1.0

First public release of the single-host control plane.

## Install

```bash
git clone https://github.com/aywengo/mercury.git
cd mercury
npm ci
```

Or:

```bash
npm install -g @aywengo/mercury
```

Requires Node.js ≥ 22.18 and `git`. First Run: [`QUICKSTART.md`](../../../QUICKSTART.md).

`mercury --version` prints `mercury-host 0.1.0`.
`GET /healthz` includes `"product": "host"` and `"version": "0.1.0"`.

## What this is

API, worker, SQLite queue, git-worktree workspaces, optional container sandbox,
structured events, dashboard, and adapters (`fake`, PrimeAgent RPC, Hermes,
Claude Code, declarative local/RPC/remote).

## Not in this release

Crew, `mercuryctl`, OIDC, Fleet (see Fleet 0.1.0), skill-snapshot execution,
production daemon mode, token/cost budget enforcement.

Known limitations: [`docs/status.md`](../../status.md).
Full notes: [`CHANGELOG.md`](../../../CHANGELOG.md).
